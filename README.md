## Алгоритм развёртывания

Временный алгоритм развертывания:

1. Загрузите архив [missing_file.zip](https://disk.yandex.ru/d/pDJ0k2CPt2fqnw) с недостающими файлами.
2. Поместите содержимое архива в корень директории проекта.
3. Запустите `app.py`, дождитесь запуска сервера.
4. Перейдите по адресу: [http://127.0.0.1:5000](http://127.0.0.1:5000)

**Альтернативный способ:**
1. Скачайте архив [RecommenderSystems.zip](https://disk.360.yandex.ru/d/M320vNYT8mtMug).
2. Запустите `app.py`, дождитесь запуска сервера.
3. Перейдите по адресу: [http://127.0.0.1:5000](http://127.0.0.1:5000)

В видео [по этой ссылке](https://disk.yandex.ru/d/pDJ0k2CPt2fqnw) представлена демонстрация работы API.
